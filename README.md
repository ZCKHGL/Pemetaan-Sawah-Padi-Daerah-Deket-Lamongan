# Pemetaan-Sawah-Padi-Daerah-Deket-Lamongan
Tentang Project
Project ini bertujuan unutk melakukan pemetaan sawah lebih tepatnya sawah padi pada kecamatan Deket, Lamongan
Yang mana nantinya setelah melakukan pemetaan pada sawah dan melakukan digitasi pada QGIS, bisa di lanjutkan untuk melakukan
pembuatan dataset menggunakan plugin Deepness

untuk langkah penggunaan
1. Download Qgis lewat web resmi
2. download zip pada repository ini
3. Extract file .zip
4. lalu buka file DEKET.qgz dengan double click pada file tersebut
5. jika bisa maka QGIS akan otomatis terbuka
6. lalu apabila ingin melakukan pembuatan dataset user harus melakukan instalasi plugin bernama deepness pada QGIS
